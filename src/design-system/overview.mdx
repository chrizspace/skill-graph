# Skill Graph design system

Two themes, both light (there is no dark mode): **Orange**, the default, and **Violet**. People switch between them in
the account menu or on their profile; the choice is kept in the browser. Every page and component uses the **semantic tokens** below (`bg-primary`, `text-critical`…), never the raw primitives, so adding
a theme recolours everything. Tokens live in `src/design-system/tokens.ts`; `pnpm tokens` generates the CSS.

## Components

Everything in `src/components`, each with its own stories. A test fails if a component has no story or is missing
from this list (`src/design-system/catalogue.ts`).

<ComponentIndex />

## Colour primitives

Raw scales. Orange is anchored at 500 on the brand orange `#ff5800`, Violet on the core purple `#a100ff` (its 50, 700 and
900 steps are the palette's tint `#f5e5ff`, mid `#7500c0` and deep `#460073` purples); neutral, red, amber, green and blue serve every
theme. Body text is `#333333`, secondary text `#555555`, surfaces `#f2f2f2`, borders `#d1d1d1`.

## Contrast

WCAG 2.2 AA: 4.5:1 for text, 3:1 for focus rings, field borders and graph nodes. The brand orange is too light for white
text and for the body ink, so buttons on it carry a darker near-black (`#1a1a1a`); the core purple takes white text (5.3:1). `tokens.test.ts` checks every pair in every theme.

<ContrastTable />

## Weights and statuses

A requirement's weight is always an icon, a label and a colour together, never colour alone. Critical is red,
Important amber, Nice to have green. A held but expired certification is shown faded (`--opacity-expired`), and still
counts as held.

## Typography

Segoe UI where it's installed, the system font elsewhere. Headings are bold: 48 px for Heading 1, 36 px for Heading 2.
